Benchmark indices

Benchmarks are the published Total Return Indices (gross), not index funds — an index fund trails its index by expenses and tracking error, which would flatter every fund measured against it. Get them from niftyindices.com → Historical Data → Total returns Index Values, then the csv format link above the table. NSE caps each export at one calendar year, so select all the yearly files at once — they are merged, not replaced. NIFTY 100 + NIFTY 500 alone cover seven categories; four years is enough for alpha and both capture ratios. Recommended: run python3 GET-TRI-DATA.py (no NSE login needed) — it writes a fresh MF-TRI-bundle.json. Then hit Load bundle. Or download yearly CSVs manually from the link above. Hit Save bundle so one file restores everything on any device.

How a fund is scored

Seven parameters: 3Y CAGR, 3Y rolling return, Jensen's alpha, Sortino, upside capture, downside capture and standard deviation. Each scores 2 when it beats both the benchmark and the category average, 1 for one of the two, 0 for neither — direction respected, so lower standard deviation and lower downside capture are wins. Composite out of 14. A parameter with no data is skipped, never scored zero.

Beta is calculated because Jensen's alpha requires it, but it is not shown or scored — neither a high nor a low beta is inherently better. Rolling returns take one 3-year window per trading day across the span and average them, matching Advisorkhoj to within 0.005 percentage points on verified windows.
