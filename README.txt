GOHIL MF STUDIO — plug and play
================================
1. Open MF-Ratings-Engine.html in Chrome (keep internet on the first time).
2. TRI loads automatically from the published pack. Banner should NOT stay yellow.
3. Rate → Large Cap → Load & score. Alpha / capture fill when TRI is ready.
4. Portfolio: paste or upload CAS PDF / Excel.
5. SWP: 2y debt + 3y hybrid + remainder equity.
6. SIP: Conservative 30/60/10, Moderate 60/30/10, Aggressive 80/10/10.
   Gold only if SIP ≥ ₹10,000. Debt slot uses Conservative Hybrid (conshybrid).

Monthly refresh (optional):
  Double-click GET-TRI-DATA.bat  OR  python3 GET-TRI-DATA.py
  Then Setup → Load bundle → MF-TRI-bundle.json

Do NOT pick the zip in Load bundle. Pick the .json.
