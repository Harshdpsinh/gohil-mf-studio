# Figma on this site

The official Figma Plugin API skill lives in [`skills/figma-use/SKILL.md`](skills/figma-use/SKILL.md).

`MF-Ratings-Engine.html` is **not** modified by this skill. Tokens and screen names are documented in `skills/figma-use/tokens.json` and `skills/figma-use/WEBSITE.md`.

To write into a Figma file you must connect Figma MCP (`use_figma`) in the agent client, then load this skill first.
